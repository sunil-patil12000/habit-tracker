# Habit Tracker

A beautiful, interactive habit tracking application built with modern web technologies to help users build and maintain healthy habits.

## Features

- **Habit Management**: Track multiple habits with customizable goals and units
- **Progress Tracking**: Visual progress bars and streak counters for each habit
- **Daily Check-ins**: Mark your progress for each habit with interactive sliders
- **Data Visualization**: Charts and graphs to visualize your habit history
- **Streaks & Motivation**: Build streaks and receive motivational messages
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Dark/Light Mode**: Automatically adapts to system preferences or user choice

## Technologies Used

- **Next.js 15**: React framework with server and client components
- **React 19**: UI library for building the interface
- **Tailwind CSS**: Utility-first CSS framework for styling
- **Framer Motion**: Animation library for smooth transitions and interactions
- **Recharts**: Composable charting library for data visualization
- **TypeScript**: Static typing for more reliable code

## Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm or pnpm package manager

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd habit-tracker
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Usage

- **Add Habits**: Start by adding habits you want to track
- **Set Goals**: Define daily goals for each habit (e.g., 8 glasses of water)
- **Track Progress**: Update your progress throughout the day
- **View Stats**: Check the dashboard for insights into your habit-forming journey
- **Stay Motivated**: Build streaks and celebrate your consistency

## Building for Production

```bash
npm run build
# or
pnpm build
```

Then start the production server:

```bash
npm start
# or
pnpm start
```

## Customization

The application uses a clean, modern UI with a gradient color scheme that can be customized through Tailwind CSS config. Each habit can be assigned different colors and icons.
